# AI 分析配置说明 (v2: 前端本地直连)

v2 起 AI 分析由**前端浏览器本地直连**大模型完成，请求不经过本项目后端，配置与历史记录均保存在**本机浏览器**。

## 配置入口

登录后进入 **「我的」页 → 「AI 设置」标签**（地址 `/#/my?tab=ai-settings`）。

## 配置项

| 配置项 | 说明 |
| --- | --- |
| 服务商 | 下拉选择常用服务商（默认 DeepSeek），或选择「自定义地址」填写任意 OpenAI 兼容接口 |
| 接口地址 | 如 `https://api.deepseek.com/v1`；本地 Ollama 可填 `http://localhost:11434/v1` |
| API Key | 在对应平台申请；仅保存在本机浏览器 localStorage，**不会上传到后端**；本地服务(Ollama)可留空 |
| 模型 | 可下拉选择/手动输入；填写地址(与 Key)后自动拉取服务商模型列表 |
| 开发模式代理 | npm run dev 时经 Vite `/ai-proxy` 转发（仅 DeepSeek 默认地址生效），规避浏览器跨域限制 |
| 测试连接 | 保存配置后点击即可验证接口连通性与模型回复 |

## 网络路径

- 开发模式(`npm run dev`): 默认经 Vite 代理 `/ai-proxy` 转发到接口地址
- Electron 生产模式: 无跨域限制，直接连接接口地址
- 自定义远程地址在开发模式也可直连（需服务端放行 CORS）

## 本地历史

题目分析与学情报告结果保存在本机浏览器（localStorage，最近 50 条），可在设置页一键清空。
