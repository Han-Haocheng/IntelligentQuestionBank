## 二、未取得材料（如实为“无”，附获取路径与条件）

### 2.1 计算机软件著作权（无 → 可申请）

- **现状**：未申请，无登记号。
- **价值**：软件类竞赛/学校科研认定的常见佐证；费用低（国家版权局登记官费免费/极低，代办除外）。
- **获取路径**：
  1. 明确权利主体：个人/团队名义还是学校名义，需先确认（在校生以学校名义申报常需学校科技处/教务处流程，版权归属与署名顺序提前约定）【占位：与学校确认】；
  2. 准备材料：软件全称与简称、版本号（建议定 v1.3.0 或更高正式版）、源代码（前后各 30 页，共 60 页，每页 50 行内）、软件说明书（可复用 README/本批文档）；
  3. 通过中国版权保护中心（ccopyright.com.cn）在线提交，审查周期通常 30~60 个工作日（加急另计）【周期占位】；
  4. 注意：申请版本号与当前发布版本一致更稳妥；第三方开源组件（Vue/Spring 等）不在申报代码范围内选择时注意避免整段拷贝组件源码。
- **负责人/时间**：【占位】

### 2.2 专利（无 → 需先评估，不建议仓促申请）

- **现状**：未申请任何专利。
- **客观提示**：本项目为典型的业务系统实现，主要创新在**产品组合与工程实现**层面，直接申请发明专利通过率低、周期长（发明 1.5~3 年），实用新型对软件系统通常不适用；不建议为申报而强申。
- **候选方向（仅作内部讨论，需先做专利检索判断新颖性，不得提前对外宣称“有专利”）**：
  - 题目批量导入与 AI 补全的“人工确认流水线”交互方法（如可专利则偏发明+软著组合）；
  - 练习/错题数据驱动的学情报告生成流程；
  - 共享场景的只读/可编辑协同与订阅拷贝机制。
- **建议动作**：【占位——是否申请、以谁名义（个人/学校）、预算】。检索途径：国家知识产权局专利检索系统、佰腾/智慧芽等。

### 2.3 第三方检测/测评报告（无 → 可选做）

- **现状**：未委托任何第三方机构测评。
- **已有替代证据**：单测 193 项 + 构建门禁 + 版本发布（见第一部分）可作“工程自证”；部分申报（如学校立项验收）接受“自测报告 + 演示验收”。
- **如需要正式报告**：委托具有 CMA/CNAS 资质的软件测评机构（如中国软件评测中心等，名录请查证【占位】）做功能/性能/安全测试并出具报告；需准备：部署环境、测试用例（可基于 README 功能清单编写）、演示数据；费用与周期因机构与项目规模而异【费用/周期占位，通常数千元起、1~4 周】。
- **负责人/时间**：【占位】

### 2.4 合作协议 / 试点单位证明（无 → 需实际开展）

- **现状**：未与任何学校/机构签署合作或试点协议。
- **切勿虚构**：如需“试点单位”类佐证，必须先真实开展试用并获得对方书面确认（试用反馈表/授权书/协议均可），流程建议：
  1. 起草《软件试用/试点协议（意向模板）》：范围（模块/期限/数据）、双方义务（数据脱敏、知识产权归属维持开源 MIT 前提下的使用边界）、反馈机制【占位：模板起草】；
  2. 对接 1~2 位真实教师/课程：用演示数据建一门课题库并试用（见 docs/02 附录 A 演示脚本），收集反馈表（截图/签字）；
  3. 反馈表要素：试用单位与联系人（需对方确认可公开）、试用时间、功能清单勾选、意见建议、签字盖章（视申报要求）。
- **试点对象建议**：团队成员所在高校的任课教师、实验室、学生组织【占位：对接人】。
